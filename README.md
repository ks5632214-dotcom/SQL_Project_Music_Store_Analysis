# 🎵 Music Store Data Analysis | SQL

## 1. Project Overview

This project analyzes a music store database using SQL to extract meaningful insights about customer behavior, sales performance, and product trends.

The goal is to transform raw relational data into **actionable business insights** using SQL queries.

## 2. Business Problem

Music stores generate large amounts of transactional data, but without analysis, it is difficult to identify:

* Top-performing countries and regions
* High-value customers
* Most popular music genres
* Best-selling artists and tracks

This project solves these problems using SQL-based analysis.

## 3. Project Objectives

* Analyze customer purchasing behavior
* Identify top revenue-generating countries
* Find most popular genres and artists
* Determine top customers by spending
* Extract insights from relational datasets
